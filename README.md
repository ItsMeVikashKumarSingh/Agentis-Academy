## 🏛️ Overview

**AgentCraft Academy** bridges the gap between toy LLM wrappers and robust, enterprise-grade multi-agent swarms. The platform features an editorial, high-trust engineering aesthetic with real-time interactive multi-agent lab simulations, modular curriculum deep dives, and an end-to-end payment gateway compliance architecture.

### Key Highlights

- **Production-Tested Curriculum:** 4 core tracks covering LangGraph cyclic graphs, self-hosted n8n clusters, local Ollama/FastMCP tool routing, and Temporal durable execution.
- **Interactive Swarm Laboratory:** Live interactive execution trace simulator demonstrating real-time deterministic tool calls, Pydantic v2 guardrail enforcement, and subtask decomposition.
- **Enterprise-Grade Design System:** Warm tactile canvas (`#fdfbf9`), precise 1.5px charcoal borders (`#171717`), Cocoa Ink display typography, and signature architectural badges.
- **Payment Gateway Compliance Suite:** Fully equipped with DPDP/GDPR-compliant Privacy Policy, Terms of Service, 14-Day Money-Back Guarantee, Digital Delivery SLA, and verified corporate contact information.

## 🚀 Getting Started

### Prerequisites

- Node.js `v20.x` or higher
- npm, yarn, or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ItsMeVikashKumarSingh/agentcraft-academy.git
   cd agentcraft-academy
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Access the application:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build & Deployment

### Build the application:
```bash
npm run build
```

### Run production server (configured for cloud containers on `0.0.0.0`):
```bash
npm run start
```

### Cloud Platforms (Antideploy / Docker / Cloud Run / Vercel)
This project is configured out of the box for containerized cloud deployment. The `start` script explicitly binds to host `0.0.0.0`, ensuring compatibility with container health checks and ingress proxies.
