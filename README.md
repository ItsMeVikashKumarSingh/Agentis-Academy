## 🚀 Quickstart & Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

4. **Production Build:**
   ```bash
   npm run build
   npm run start
   ```
   *(Configured with `Procfile` and `-H 0.0.0.0` for cloud container hosting on Antideploy, Docker, and Cloud Run)*
