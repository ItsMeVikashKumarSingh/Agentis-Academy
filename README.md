# AgentCraft — AI Agents & Automation Academy (Template-2)

An editorial, tactile course-selling landing page for AI agents, multi-agent systems, and workflow automation, meticulously crafted in the **Superr aesthetic**.

## Style & Design Tokens (Superr Theme)

- **Canvas Ground:** Warm Cream Paper (`#fdfbf9`) with Dew Drop secondary surfaces (`#f7efe9`).
- **Inks & Borders:** Charcoal (`#171717`) thin 1.5px borders and structural edges, Cocoa Ink (`#2b1a07`) for warm display headlines.
- **Accents:** Marker Orange (`#ff6f1e`) exclusively for handwritten annotations, underlines, and the footer closer band.
- **Buttons:** Superr Pill Action Buttons with cream fill, 1.5px Charcoal border, 20px radius, and subtle 1–2px paper lift shadow.
- **Notebook Assets:** Physical lab notebook cards with laminated name stickers (`Name`, `Class`, `Roll no.`), tilted 5–8°.
- **Stickers:** Peel-and-stick vector illustrations (Lightning bolt in Sky Blue, Robot Bear in Bubblegum, Sparkles in Sprout Green, Terminal) rotated 5–15° at random with 2px dark outlines.
- **Footer Closer:** Signature 56px top-rounded asymmetric Marker Orange band (`we're done, and we had fun.`).

## Getting Started

Run the development server:

```bash
cd Template-2
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
